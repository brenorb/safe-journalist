# Feature 0001: Module Refactoring

## Brief

Refactor `src/safe_journalist/__init__.py` so we have separation of concerns, splitting session/crypto/transport/CLI logic into focused modules while preserving current behavior.

---

## Scope and Targets

- **`src/safe_journalist/__init__.py`**: Currently contains Maple session dataclass, attestation decoding, key exchange, encrypted call, and CLI `main`.
- **New modules to create** under `src/safe_journalist/` to isolate responsibilities:
  - `session.py`: Maple session data model and session creation workflow
  - `attestation.py`: Decoding and public key extraction
  - `crypto.py`: Base64 helpers and ChaCha20-Poly1305 encryption/decryption helpers
  - `client.py`: HTTP transport wrapper for key exchange and encrypted OpenAI call
  - `cli.py`: `main()` entry point and env parsing
- **`src/safe_journalist/__init__.py`**: Turn into a minimal public API surface re-exporting key functions/classes

---

## Behavioral Algorithm Details

### Existing Flow to Preserve

#### 1. Attestation

- GET `{api_url}/attestation/{nonce}`
- Decode base64 to CBOR bytes
- Parse COSE_Sign1 array `[protected, unprotected, payload, signature]`
- Decode `payload` CBOR, ensure `public_key` exists
- Accept `public_key` as bytes or list of ints; return bytes

#### 2. Key Exchange

- Generate X25519 client key pair via NaCl `PrivateKey.generate()`
- POST `{api_url}/key_exchange` with `client_public_key` (base64) and `nonce`
- Receive `encrypted_session_key` (base64) and `session_id`

#### 3. Session Key Decryption

- Compute shared secret with `crypto_scalarmult(client_sk, server_public_key)`
- Decrypt encrypted session key using ChaCha20-Poly1305:
  - Nonce = first 12 bytes
  - Ciphertext = remaining bytes
  - `aead.decrypt(nonce, ciphertext, None)`

#### 4. Encrypted OpenAI Call

- JSON-encode payload
- Encrypt with session key using ChaCha20-Poly1305:
  - Random 12-byte nonce
  - Prepend nonce to ciphertext
- POST `{api_url}{path}` with headers:
  - `Authorization: Bearer {api_key}`
  - `x-session-id: {session_id}`
  - `Accept-Encoding: identity`
- Read `encrypted` from response, base64 decode, split nonce/ciphertext, decrypt, JSON decode

## Refactor Steps

### 1. Data/Crypto Layer

- Move `_b64encode`/`_b64decode` and ChaCha20-Poly1305 encrypt/decrypt helpers into `crypto.py`
- Keep signatures to preserve behavior and byte formats

### 2. Attestation Layer

- Move `_extract_public_key_from_attestation` into `attestation.py`
- Keep hackathon-mode behavior: no signature verification, only CBOR decode

### 3. Session Layer

- Move `MapleSession` dataclass and `create_session` into `session.py`
- `create_session` should call `attestation` + `crypto` helpers and use a transport helper for HTTP calls

### 4. Client/Transport Layer

- Move `encrypted_openai_call` into `client.py`
- Keep request headers and payload structure identical

### 5. CLI Layer

- Move `main()` into `cli.py` and keep env parsing and request payload intact
- `__init__.py` should re-export `MapleSession`, `create_session`, `encrypted_openai_call`, and optionally `main` if used as entry point
