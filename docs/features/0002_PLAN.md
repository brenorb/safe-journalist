# Feature 0002: FastAPI Text Storage API

## Brief

Build a FastAPI API that accepts text and stores it on disk as `/data/<timestamp>.md`.

---

## Scope and Targets

- Create a FastAPI app module (e.g. `src/safe_journalist/api.py`) with a single endpoint to accept text and persist it
- Add a small storage helper module (e.g. `src/safe_journalist/storage.py`) to isolate filesystem writes
- Update `pyproject.toml` to include FastAPI and an ASGI server dependency
- Update `README.md` with minimal run instructions and example request
- Add a focused API test file (e.g. `tests/test_api.py`) to verify the write path and file contents
- Optionally re-export the FastAPI `app` from `src/safe_journalist/__init__.py` if the package entrypoint is expected to expose it

---

## Implementation Details

### 1. Request Schema

- Accept JSON body with a single `text` field (string)
- Return JSON containing the saved file path and timestamp used for the filename

### 2. Timestamp → Filename

- Generate a filesystem-safe timestamp string (UTC `YYYYMMDDTHHMMSSZ`)
- Build the full path `/data/<timestamp>.md`

### 3. Storage Behavior

- Ensure the `/data` directory exists before writing
- Write the raw text to the `.md` file with UTF-8 encoding
- Fail fast with a clear 4xx if `text` is missing/empty; 5xx for unexpected IO errors

### 4. Endpoint Flow

- Validate input
- Call storage helper to write the file
- Return the path and timestamp in the response payload

---

## Test Coverage

- ✓ POST valid JSON with `text` writes a file to `/data/<timestamp>.md`
- ✓ File contents match the request body exactly
- ✓ Empty or missing `text` returns a 4xx error and does not write a file
