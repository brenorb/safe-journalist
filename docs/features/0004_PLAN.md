# Feature 0004: Alert Endpoint

## Brief

Create a `/alert` endpoint that retrieves and returns the latest summary for emergency contacts to quickly access the most recent actionable information.

---

## Known Considerations

No directly relevant past solutions found in compound knowledge base. This is a straightforward read endpoint leveraging existing storage functions.

---

## Implementation Details

### 1. Add Alert Endpoint to API

#### Update `src/safe_journalist/api.py`

Add new GET endpoint `/alert`:

1. **Route**: `@app.get("/alert")`
2. **Function**: `get_alert()`
3. **Logic**:
   - Get `base_dir` using `get_data_dir()`
   - Call `storage.get_latest_summary(base_dir)` to retrieve the most recent summary
   - If no summary exists (returns `None`), raise `HTTPException(status_code=404, detail="No summary available yet")`
   - If summary exists, return the summary content
4. **Response Model**: Create `AlertOut` Pydantic model with:
   - `summary: str` - the summary text content
   - `timestamp: str` - extracted from the summary filename (format: `YYYYMMDDTHHMMSSZ`)
   - `path: str` - the file path of the summary

#### Response Model Definition

```python
class AlertOut(BaseModel):
    summary: str
    timestamp: str
    path: str
```

### 2. Summary Timestamp Extraction

The timestamp is embedded in the summary filename pattern `<timestamp>-summary.md`. Extract it by:
1. Get the `Path` object's `.stem` attribute (filename without extension)
2. Remove the `-summary` suffix
3. Return the remaining timestamp string
