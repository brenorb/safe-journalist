# Feature 0006: Configurable Prompt Templates for Summarization

## Brief

Refactor hardcoded AI summarization prompts into external, configurable templates stored in a dedicated templates directory. Implement DRY principle by splitting prompts into composable parts (context-specific prefix + shared instruction) that concatenate when needed.

---

## Scope and Targets

- Create `/src/safe_journalist/templates/` directory with prompt template files
- Create two template files: `summary_instructions.txt` (shared base) and `summary_context.txt` (context-specific prefixes)
- Update `summarizer.py` to load and compose templates at runtime
- Ensure templates are packaged with the distribution via `pyproject.toml`
- Make prompts easily editable without touching Python code

---

## Implementation Details

### 1. Template Directory Structure

Create new directory: `src/safe_journalist/templates/`

**Files:**
- `summary_instructions.txt` - Shared instruction template (DRY base)
- `summary_context.txt` - Context-specific prefixes with placeholders

### 2. Template Content Design

#### `summary_instructions.txt` (Base Template - DRY)
```
Generate a concise 3-5 bullet summary with the most relevant and up to date actionable information for emergency contacts.
```

#### `summary_context.txt` (Context Prefixes)
```
[WITH_PREVIOUS_SUMMARY]
Previous summary:
{summary_content}

New notes:
{entries_text}

[NO_PREVIOUS_SUMMARY]
Notes from journalist:
{entries_text}
```

**Format Notes:**
- Use `[SECTION_NAME]` markers to delineate different context scenarios
- Use `{placeholder}` syntax for variable interpolation
- Each section ends at the next `[SECTION_NAME]` or EOF

### 3. Template Loading Module

#### Update `summarizer.py`

Add module-level template loading functions:

**`load_template(filename: str) -> str`**
- Accepts filename (e.g., "summary_instructions.txt")
- Returns raw template content as string
- Uses `Path(__file__).parent / "templates" / filename` to locate files
- Raises clear error if template file missing

**`parse_context_template(template_content: str) -> dict[str, str]`**
- Parses `summary_context.txt` format with `[SECTION_NAME]` markers
- Returns dict mapping section names to their content
- Example: `{"WITH_PREVIOUS_SUMMARY": "Previous summary:\n...", "NO_PREVIOUS_SUMMARY": "Notes from journalist:\n..."}`

**`build_prompt(context_key: str, variables: dict[str, str]) -> str`**
- Accepts context key (e.g., "WITH_PREVIOUS_SUMMARY" or "NO_PREVIOUS_SUMMARY")
- Accepts dict of variables for interpolation (e.g., `{"summary_content": "...", "entries_text": "..."}`)
- Loads context template section and base instructions
- Interpolates variables using `.format(**variables)`
- Concatenates context prefix + base instructions
- Returns complete prompt ready for AI

### 4. Update `generate_summary` Function

Refactor existing prompt construction in `summarizer.py`:

**Current code (lines 46-60):**
- Hardcoded f-strings with prompt text
- Duplicated instruction text in both branches

**New approach:**
1. Load templates at module level (cached for performance):
   ```python
   # Module-level template loading (cached)
   SUMMARY_INSTRUCTIONS = load_template("summary_instructions.txt")
   CONTEXT_TEMPLATES = parse_context_template(load_template("summary_context.txt"))
   ```

2. Replace prompt construction logic:
   - **If previous summary exists**: Use `build_prompt("WITH_PREVIOUS_SUMMARY", {"summary_content": ..., "entries_text": ...})`
   - **If no previous summary**: Use `build_prompt("NO_PREVIOUS_SUMMARY", {"entries_text": ...})`

3. Pass constructed prompt to `encrypted_openai_call` (no changes to AI call logic)

### 5. Package Configuration

#### Update `pyproject.toml`

Add package data configuration to include templates:

```toml
[tool.setuptools.package-data]
safe_journalist = ["templates/*.txt"]
```

Or if using modern `pyproject.toml` without setuptools backend:

```toml

```

**Verification**: After installation via `uv pip install .`, templates should be accessible from `importlib.resources` or `Path(__file__).parent / "templates"`

### 6. Error Handling

Add clear error messages if templates are missing:

- Raise `FileNotFoundError` with helpful message: "Summarization template not found: {path}. Ensure templates/ directory is packaged correctly."
- Include fallback to inline prompts if templates missing (optional, for development ergonomics)
